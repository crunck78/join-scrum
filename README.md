# Join-SCRUM

It features a SCRUM like board UI. Were you can create boards and lists for your tasks and categorize them.
The task can be transitioned and ordered between lists by drag and drop.
You can also add subtasks to your tasks.

Besides you can create your contacts that ca be assigned to tasks.
